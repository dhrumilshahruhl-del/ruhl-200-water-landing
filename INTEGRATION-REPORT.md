# 200 Water Street / Rooftop Virtual Showroom integration

1. **Added:** `virtual-showroom/` (isolated runtime modules, local Three.js 0.170.0, 31 runtime assets, shell, mount API, LICENSE and Third-Party Notices), `showroom-integration.js`, `package.json`, production packaging and browser QA scripts.
2. **Changed existing files:** `index.html`, `building-scroll.js`, `model-preload.js`, `wrangler.jsonc`, `README.md`. Parent `styles.css` and `main.js` are unchanged. Existing unrelated files remain in place.
3. **CTA:** The unchanged “Explore rooftop systems” button dynamically imports the mount module. A native fullscreen modal contains the showroom in a Shadow DOM; there is no iframe, navigation, or extra history entry.
4. **Old rooftop:** Its controller import and construction are removed. Its overlay and roof preloading are removed. Legacy source files remain available locally but are excluded from production. The existing building scroll tour retains its own renderer, model and dependencies.
5. **Lazy loading:** Network QA confirms no `/virtual-showroom/` requests before CTA activation. Runtime, assets and local Three.js load afterward. No old roof assets are requested.
6. **Dependencies:** Both projects use r170. The parent keeps its CDN graph; the showroom keeps its local graph using an import-map scope. No dependency versions were merged or changed. No global THREE object is introduced. Existing parent CDN origins are unchanged.
7. **Isolation:** Native modal semantics make the parent inert. Shadow DOM isolates CSS in both directions. Host styles reproduce the standalone document styles. Module-relative URLs support root and `/200-water/` hosting. Parent integration state stays module-local.
8. **Cleanup:** Three open/close cycles release the added WebGL context and return RAF/global listeners to baseline. DOM listener count is stable across cycles; collected JS heap stays near 15 MB. Runtime observers, controls, scene resources, city leases, cached models and renderer are disposed; transient DOM is removed. Page scroll, camera progress and CTA focus are restored. Parent rendering pauses while open; motion preference changes are reconciled at close.
9. **Parent QA:** Original main content and computed typography match at 1440, 1280, 1024, 768 and 390 px. Parent styles/main script are untouched. Scroll tour and CTA work with the original CDN dependencies. No failed requests or page exceptions were recorded in the final functional suite.
10. **Showroom QA:** Six approved flow steps, Previous/Next/Pause/Resume/Restart/Exit, equipment dialogs, Legal & Credits, notices link, reduced motion, responsive controls and repeated opening pass. Keyboard rotation/zoom/reset, OrbitControls dragging, /200-water/ asset loading and modal focus isolation are verified. Integrated showroom, active flow and legal WCAG scans report no violations. Simulated document visibility changes stop and resume rendering. Keyboard Escape retains the nested dialog ? flow ? showroom hierarchy. Actual Chrome zoom at 200% is verified (DPR 2 and reflowed viewport); the existing flow panel scrolls to reach its controls. Asset bytes, approved impact configuration, flow data, focus/choreography data and notices match the standalone production copy.
11. **Production:** `npm run build` creates an allowlisted `dist/` with 80 runtime files plus the generated manifest. Cloudflare configuration now serves `dist/`. Old roof models/controllers, development/audit documents, scripts and source asset kits are excluded. Build and syntax checks pass. No deployment was performed.
12. **Remaining scope:** Browser QA uses desktop Chrome, including responsive viewport emulation; physical mobile devices and other browser engines were not independently audited. The standalone source and deployment are unchanged.

The integrated showroom preserves the tested standalone runtime and behaves equivalently in the verified workflows, with no parent-site regression detected.
